Nexora Institute of Technology


Project Description

Nexora Institute of Technology is a Code Academy website developed using HTML5 and CSS3. It provides information about technology courses, student benefits, and the academy.

1. Which HTML elements did you use to structure the website?
I used semantic HTML elements such as `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>` to organize the website. I also used headings, paragraphs, links, and other HTML elements to display the content.

2. How did you arrange the course cards?
I used CSS Grid to arrange six course cards in three columns on desktop screens. The cards have equal spacing, borders, and hover effects.

3. Which CSS property did you find most useful, and why?
I found the `display: grid` property most useful because it helped me arrange the course cards neatly in rows and columns. It also made it easier to adjust the layout for different screen sizes.

4. What problem did you face during development, and how did you solve it?
I faced problems with spacing and alignment between different sections and course cards. I solved these problems by adjusting margin, padding, gap, and box-sizing properties in CSS.

5. How did you make your website responsive?
I used CSS media queries to make the website responsive. I adjusted the course cards, navigation, and About section for tablet and mobile screens. On smaller screens, the cards change to fewer columns and the About section changes to a single-column layout.
